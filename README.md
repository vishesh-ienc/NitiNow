🚀 NitiNow

NitiNow is a web-based prototype that helps young citizens easily discover government schemes relevant to their needs. 🇮🇳

Many students, job seekers, and working professionals struggle to navigate complex government portals and understand eligibility criteria. NitiNow simplifies this process through a guided and user-friendly interface.

✨ What It Does

🎓 Allows users to select their profile (Student, Job Seeker, Working Professional, etc.)

📊 Collects basic details like age, income range, and state

🧠 Uses rule-based filtering to recommend relevant government schemes

📄 Displays simplified explanations of each scheme

🔗 Redirects users to official application links

🌍 Vision

NitiNow aims to bridge the gap between citizens and public welfare schemes by making policy awareness simple, accessible, and transparent.
